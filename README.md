# 💊 Medicare Reminder

AI-powered prescription reader + family medicine tracker.

\---

## ▶️ How to Run (Step by Step)

### Step 1 — Install Node.js

Download from: https://nodejs.org  
Choose "LTS" version → Install it

### Step 2 — Open the project folder in VS Code terminal

```
cd medicare-reminder
```

### Step 3 — Install packages (only once)

```
npm install
```

### Step 4 — Start the app

```
npm start
```

### Step 5 — Open in browser

```
http://localhost:3000
```

\---

## 📁 Files

```
medicare-reminder/
├── server.js       ← Node.js server (handles Claude API calls)
├── config.json     ← Your Anthropic API key
├── package.json    ← Dependencies
└── public/
    └── index.html  ← Full React frontend
```

\---

## 🔑 To Change API Key

Edit `config.json`:

```json
{
  "apiKey": ""
}
```

\---

## ✨ Features

* 📷 Upload any prescription (handwritten or printed) → AI reads it
* 👤 Patient login → scan prescriptions, track medicines
* 👨‍👩‍👧 Family login → use patient's alternate phone number
* ✅ Taken / ❌ Not Taken buttons with time tracking
* 🔔 Real-time family notifications
* 🗓️ Calendar view
* 🗑️ Clear schedule option
